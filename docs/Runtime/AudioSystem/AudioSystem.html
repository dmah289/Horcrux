Tổng quan

Phát SFX 2D và một bài nhạc nền theo id enum của dự án. Game gọi _audio.PlaySfx(GameSfx.Click); dữ liệu clip nằm trong một asset catalog do game điền, SDK không biết clip nào.

  • SFX: nhiều tiếng cùng lúc, mỗi lần phát lệch cao độ ±5%, một tiếng bị gọi dồn trong cùng frame chỉ phát một lần, 0 B cấp phát ở đường phát.
  • Music: một bài loop, đổi bài là cắt rồi phát bài mới, bật/tắt độc lập với SFX.
  • Không UniTask, không Addressables, không phụ thuộc hệ Horcrux nào khác (Foundation).
Thêm tiếng là thêm số enum và một entry catalog.

Id là enum của dự án: compiler chặn GameMusic.Level truyền vào PlaySfx, Inspector vẽ dropdown tên.

Cách dùng

SDK và dự án

Phụ thuộc một chiều: dự án tham chiếu SDK, SDK không biết gì về dự án.

Hai class con rỗng là bắt buộc: generic MonoBehaviour/ScriptableObject không add/create được, và [Service] / [CreateAssetMenu] không dùng được trên generic.

Trước khi chạy

Dựng từ 0 theo thứ tự; mỗi bước kèm chỗ hỏng nếu thiếu.

  1. Khai id và hai class con (một lần cho dự án) 
    // enum: gán số TƯỜNG MINH, bắt đầu từ 1 — 0 là "chưa gán"
public enum GameSfx   { Click = 1, Win = 2 /* … */ }
public enum GameMusic { Level = 1 }

[CreateAssetMenu(fileName = "AudioCatalog", menuName = "Game/Audio Catalog")]
public sealed class GameAudioCatalog : AudioCatalog<GameSfx, GameMusic> { }

[Service(typeof(IAudioService<GameSfx, GameMusic>), typeof(IAudioSetting), FindFromScene = true)]
public class GameAudioService : AudioService<GameSfx, GameMusic> { }

    Số trong enum là wire format của asset: không đánh số lại, chỉ thêm số mới. Thiếu [Service] trên GameAudioService: không ai resolve được IAudioService<…>, consumer không nhận được service.

  2. Dựng catalog
    1. Create → Game → Audio Catalog (tên menu do [CreateAssetMenu] của bạn khai).
    2. Entries: mỗi tiếng một phần tử — chọn Id từ dropdown GameSfx, kéo Clip, chỉnh Volume (mặc định 1) và Min Interval Seconds (mặc định 0.03).
    3. Tracks: mỗi bài nhạc một phần tử — Id từ dropdown GameMusic, Clip, Volume.
    4. Bấm Validate Entries: Console phải có một dòng log, không error.
    ThiếuHỏng ở đâu
    Entry của một idPlaySfx log [AudioService]: Sfx X is not in the catalog, không phát
    Track của một idPlayMusic log [AudioService]: Music X is not in the catalog, giữ bài hiện tại
    Hai entry cùng idBuildTables ném ArgumentException ở Awake của host
    Clip của entryNRE ở lần PlaySfx đầu tiên của id đó
  3. Dựng host trong scene
    1. Scene sống suốt phiên chơi (scene persistent / bootstrap của game): tạo GameObject audio, Add Component GameAudioService.
    2. Kéo catalog vào ô Catalog.
    3. Bấm Setup Audio Sources: tạo 8 GameObject con sfx_voice_0..7 + music_source, điền vào Voices / Music Source, ép cờ (Play On Awake tắt, Spatial Blend = 0, Loop tắt; riêng music Loop bật). Bấm lại chỉ bù ô thiếu. Muốn nhiều voice hơn: thêm ô vào mảng rồi bấm lại.
    4. Bấm Validate References: một dòng log, không error. Lưu scene.
    ThiếuHỏng ở đâu
    Ô CatalogNRE ở Awake của host
    Music SourceNRE ở lần PlayMusic hay set IsMusicOn đầu tiên
    Voices rỗngIndexOutOfRange ở lần PlaySfx đầu tiên
    Một ô voice NoneNổ trễ: chỉ chạm khi các voice trước đã bận — đúng lúc combo dồn
    Host ở scene bị unloadHost bị destroy cùng scene; host không DontDestroyOnLoad
  4. Nối Setting (bật/tắt Sound, Music)

    Service không biết hệ lưu của game: game tự ghi hai cờ từ save của nó. Consumer chỉ cần hai cờ nên lấy IAudioSetting (không generic, không phải gọi tên enum của dự án):

    public class AudioSettingBridge : MonoBehaviour<IMySaveData, IAudioSetting>
{
    private IMySaveData _save;
    private IAudioSetting _audio;

    protected override void Init(IMySaveData save, IAudioSetting audio)
    {
        _save = save;
        _audio = audio;

        _audio.IsSfxOn = _save.SoundOn;                  // áp giá trị đã lưu ngay lúc khởi động
        _audio.IsMusicOn = _save.MusicOn;
        _save.OnSoundChanged += SetSfx;                  // rồi bám theo mỗi lần người chơi đổi
        _save.OnMusicChanged += SetMusic;
    }

    private void OnDestroy()
    {
        _save.OnSoundChanged -= SetSfx;
        _save.OnMusicChanged -= SetMusic;
    }

    private void SetSfx(bool on) => _audio.IsSfxOn = on;
    private void SetMusic(bool on) => _audio.IsMusicOn = on;
}

    Đặt component trên GameObject audio. Cờ có thể được ghi trước Awake của host: an toàn. Thiếu cầu nối: hai cờ giữ mặc định bật, người chơi tắt tiếng trong Setting không có tác dụng.

Nhận service

Nhận qua InitArgs, không static. Initializer thêm trên prefab; để ô argument trống thì lấy từ service.

// class đã có base riêng: IInitializable + gắn Initializer (component ẩn) trên prefab
public class Button : BaseWidget, IInitializable<IAudioService<GameSfx, GameMusic>>
{
    private IAudioService<GameSfx, GameMusic> _audio;
    public void Init(IAudioService<GameSfx, GameMusic> audio) => _audio = audio;
}

// class MonoBehaviour thuần: MonoBehaviour<T>, tự nhận, không cần Initializer
public class Player : MonoBehaviour<IAudioService<GameSfx, GameMusic>>
{
    private IAudioService<GameSfx, GameMusic> _audio;
    protected override void Init(IAudioService<GameSfx, GameMusic> audio) => _audio = audio;
}

Phát tiếng, phát nhạc

_audio.PlaySfx(GameSfx.Click);            // cao độ ngẫu nhiên ±5%
_audio.PlaySfx(GameSfx.Jump, 1.26f);      // cao độ chỉ định, không jitter
_audio.PlayMusic(GameMusic.Level);        // vào màn; gọi lại cùng bài thì không restart
_audio.StopMusic();

Một tiếng nhiều bậc (combo, chuỗi)

Cách chính: mỗi bậc một entry với clip thu sẵn, rồi chọn entry theo bậc và kẹp ở bậc cuối. Clip thu sẵn nghe hay hơn một clip bị đẩy pitch cao (ngắn lại, mỏng đi).

private static readonly GameSfx[] ComboSfxs = { GameSfx.Combo2, GameSfx.Combo3, GameSfx.Combo4 };

_audio.PlaySfx(ComboSfxs[Mathf.Min(combo, ComboSfxs.Length + 1) - 2]);   // combo ≥ 2; từ bậc cuối trở đi lặp tiếng cuối

Khi chỉ có một clip và muốn tăng dần bằng cao độ, dùng PlaySfx(sfx, pitchScale); công thức do call site giữ, ví dụ nửa cung mỗi bậc:

float pitchScale = Mathf.Pow(2f, Mathf.Min(step, maxStep) * semitonesPerStep / 12f);
_audio.PlaySfx(GameSfx.Combo, pitchScale);

Thêm một tiếng mới

  1. Thêm giá trị vào GameSfx với số mới (không dùng lại số đã xoá).
  2. Thêm entry vào catalog, Validate Entries.
  3. Gọi _audio.PlaySfx(GameSfx.X).

Flow

Phát một tiếng
_audio.PlaySfx(GameSfx.Click) ├─ IsSfxOn = false ─────────────────────────> im lặng (hợp lệ) ├─ id không có trong catalog ───────────────> LogError, bỏ ├─ now − lần phát trước của entry < minInterval ─> bỏ (throttle, hợp lệ) ├─ pitch = random [0.95, 1.05] (hoặc pitchScale nếu dùng PlaySfx(sfx, pitchScale)) ├─ voice = rảnh đầu tiên, hết thì cướp voice sắp xong nhất └─ voice.clip/volume/pitch ← entry ; Play() busyUntil[voice] = now + clip.length / pitch

Voice rảnh khi now ≥ busyUntil và !isPlaying.

Nhạc

PlayMusic(id) ── id không có trong catalog ──> LogError, giữ bài hiện tại └─ nhớ bài ──────────────────┐ StopMusic() ──── bỏ chọn bài ──────────────┤ IsMusicOn = x ─────────────────────────────┴─> áp trạng thái nhạc tắt, hoặc chưa chọn bài ──> musicSource.Stop() đang phát đúng clip ──────> giữ nguyên: không restart, volume cũ còn lại ──────────────────> volume, clip ← track ; Play() từ đầu

Lưu ý

[Service] không di truyền. Inherited = false: khai ở AudioService base không tới class con. Phải đặt trên GameAudioService.
Override Awake hay ConfigureAllSources thì phải gọi base. Class con đặt trùng tên sẽ che hẳn bản base: bảng tra không dựng, mốc throttle không điền, cờ voice không ép — im lặng. ConfigureAllSources chỉ có trong Editor: override phải nằm trong #if UNITY_EDITOR, không thì build player lỗi compile.
Enum phải gán số tường minh từ 1, không đánh số lại. 0 là "chưa gán"; số là wire format của asset. Enum long không hỗ trợ (Unity lưu enum thành int).
Ô voice None nổ trễ. Chỉ chạm khi các voice trước đã bận, đúng lúc combo dồn. Bắt bằng Validate References từ lúc authoring.
Không guard runtime cho catalog / music source / voice / clip null. Mỗi cái nổ thật ở lần chạm đầu; nút Validate báo sớm hơn. Validate chỉ chạy khi bấm: không OnValidate, không chạy ở Awake.
Không DontDestroyOnLoad. Host là component trong scene; đời sống do scene quyết. Đặt nó ở scene sống suốt phiên chơi.
Hợp đồng pitchScale > 0 do caller giữ. pitchScale rất gần 0 cũng ra cao độ ngẫu nhiên.
Throttle khoá theo entry. Cùng một clip ở hai entry thì throttle riêng.
SFX và music được trùng số với nhau: hai bảng độc lập; compiler chặn GameMusic.Level truyền vào PlaySfx.
