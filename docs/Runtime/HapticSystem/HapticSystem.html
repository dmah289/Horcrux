Cách dùng

Trước khi chạy

Dựng từ 0 theo thứ tự; mỗi bước kèm chỗ hỏng nếu thiếu.

  1. Khai id và class con (một lần cho dự án) 
    // enum: gán số TƯỜNG MINH, bắt đầu từ 1 — mỗi id là một KHOẢNH KHẮC gameplay, không phải một kiểu rung
public enum GameHaptic { Tap = 1, Complete = 2 }

[Service(typeof(IHapticService<GameHaptic>), typeof(IHapticSetting), FindFromScene = true)]
public class GameHapticService : HapticService<GameHaptic> { }

    Số trong enum là wire format của scene: không đánh số lại, chỉ thêm số mới.

    Assembly của game không cần tham chiếu Lofelt.NiceVibrations: PresetType chỉ nằm trong field private của host.

    ThiếuHỏng ở đâu
    [Service] trên GameHapticServiceKhông ai resolve được IHapticService<GameHaptic>; client báo thiếu đối số lúc spawn
    Class con rỗng — không khai AwakeAwake của host là private: class con khai Awake thì Unity chỉ gọi bản của con, không gọi được base.Awake() ⇒ lib không nạp, bảng tra rỗng: cổng bật thì mọi Play log is not in the entries
  2. Dựng host trong scene
    1. Scene sống suốt phiên chơi (scene service / bootstrap của game): tạo GameObject, Add Component GameHapticService.
    2. Ô Entries (dưới tiêu đề Configs): mỗi khoảnh khắc một dòng — Id từ dropdown GameHaptic, Preset từ dropdown PresetType. Dòng mới mặc định Selection (PresetType.Selection = 0): đổi preset sau khi thêm dòng.
    3. Lưu scene.
    ThiếuHỏng ở đâu
    Dòng của một idPlay log [HapticService]: Haptic X is not in the entries., không rung
    Hai dòng cùng idArgumentException ở Awake của host
    Đổi preset sau khi thêm dòngRung Selection — không log
    Host ở scene sống suốt phiênHost bị destroy cùng scene; host không DontDestroyOnLoad
  3. Nối Setting (bật/tắt Vibration)

    Service không biết hệ lưu của game: game tự ghi cổng từ save của nó. Consumer chỉ cần cổng nên lấy IHapticSetting (không generic, không phải gọi tên enum của dự án):

    public class HapticSettingBridge : MonoBehaviour<IMySaveData, IHapticSetting>
{
    private IMySaveData _save;
    private IHapticSetting _haptic;

    protected override void Init(IMySaveData save, IHapticSetting haptic)
    {
        _save = save;
        _haptic = haptic;

        _haptic.IsHapticEnabled = _save.VibrationOn;     // áp giá trị đã lưu ngay lúc khởi động
        _save.OnVibrationChanged += SetEnabled;          // rồi bám theo mỗi lần người chơi đổi
    }

    private void OnDestroy() => _save.OnVibrationChanged -= SetEnabled;

    private void SetEnabled(bool on) => _haptic.IsHapticEnabled = on;
}

    Đặt component trên cùng GameObject với host.

    ThiếuHỏng ở đâu
    BridgeCổng mặc định false: im cả phiên, không log

Nhận service và rung

Nhận service qua InitArgs, không static. Gọi rung ngay cạnh dòng SFX của cùng khoảnh khắc:

// class đã có base riêng: IInitializable + gắn Initializer trên prefab
public class Piece : BaseEntity, IInitializable<IAudioService<GameSfx, GameMusic>, IHapticService<GameHaptic>>
{
    private IAudioService<GameSfx, GameMusic> _audio;
    private IHapticService<GameHaptic> _haptic;

    public void Init(IAudioService<GameSfx, GameMusic> audio, IHapticService<GameHaptic> haptic)
    {
        _audio = audio;
        _haptic = haptic;
    }

    public void PlayPressFeedback()
    {
        _audio.PlaySfx(GameSfx.Tap);
        _haptic.Play(GameHaptic.Tap);       // ngay cạnh SFX của cùng khoảnh khắc
        PlayPressTween();
    }
}

Initializer trên prefab: để ô haptic trống thì lấy từ service.
