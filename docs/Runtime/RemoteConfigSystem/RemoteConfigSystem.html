Cách dùng

Trước khi chạy

Dựng từ 0 theo thứ tự; mỗi bước kèm chỗ hỏng nếu thiếu.

  1. Provider. Dự án có gói com.google.firebase.remote-config thì không viết gì: asmdef com.horcrux.firebase bật qua define HORCRUX_FIREBASE_REMOTE_CONFIG và FirebaseRemoteConfigProvider tự đăng ký [Service(typeof(IRemoteConfigProvider))]. Vendor khác: tự cài IRemoteConfigProvider theo hợp đồng ở Hợp đồng provider, mang [Service(typeof(IRemoteConfigProvider))].
  2. Interface collection. Trong assembly dự án: 
    public partial interface IGameRemoteConfig : IRemoteConfigCollection, IService<IGameRemoteConfig> { }
  3. Class collection. Cùng namespace với interface: 
    [Service(typeof(IGameRemoteConfig), ResourcePath = RESOURCE_PATH)]
[CreateAssetMenu(fileName = "GameRemoteConfig", menuName = "Configs/GameRemoteConfig")]
public partial class GameRemoteConfig : BaseRemoteConfigCollection, IGameRemoteConfig
{
    private const string RESOURCE_PATH = "Config/GameRemoteConfig";
}
    partial để chia biến theo nhóm ra nhiều file (GameRemoteConfig.Level.cs…), mỗi nhóm một cặp file class + interface.
  4. Asset. Project window → Create → Configs → GameRemoteConfig, đặt ở Assets/…/Resources/Config/GameRemoteConfig.asset. Đường dẫn sau Resources/, bỏ đuôi, phải bằng RESOURCE_PATH.
  5. Mỗi biến. Hai chỗ, luôn đi cùng nhau: 
    public partial interface IGameRemoteConfig
{
    RemoteConfig<int> MaxRetryCount { get; }
}

public partial class GameRemoteConfig
{
    [Splitter("Level")]                       // tuỳ chọn — tiêu đề nhóm trong Inspector
    [MarkedRemoteConfig]
    [SerializeField] private RemoteConfig<int> maxRetryCount;

    public RemoteConfig<int> MaxRetryCount => maxRetryCount;
}
    Chọn asset, trong Inspector điền Firebase Key, Allow Fetching, Value của biến đó.
  6. Màn boot. Gọi Initialize, rồi fetch và chờ xong mới vào game: 
    IGameRemoteConfig.Service.Initialize();
await remoteConfigProvider.FetchAndActivateAsync(TimeSpan.FromSeconds(2), destroyCancellationToken);
    remoteConfigProvider nhận qua InitArgs hoặc IRemoteConfigProvider.Service. Thứ tự hai lời gọi không quan trọng.
  7. Console Firebase. Khai cùng key, giá trị cùng định dạng ở Parse theo kiểu T. Chạy tool RemoteConfigDiff (docs/Editor/RemoteConfigDiff.md) để so asset với template console.

Gọi gì, khi nào

Truy cập qua IGameRemoteConfig.Service (thiếu thì ném) hoặc IGameRemoteConfig.TryGet(out var rc).

Parse theo kiểu T

Cùng một hàm cho remote, cache, nút Import Json và tool RemoteConfigDiff.

TCách parseChú ý
stringnguyên chuỗi
enumEnum.Parsephân biệt hoa thường; nhận cả số, kể cả số không khai trong enum
int · longParse
boolbool.Parsenhận true/false không phân biệt hoa thường; 1/0 là trượt
float · doubleParse với InvariantCultureserver phải dùng dấu chấm
còn lạiJsonConvert.DeserializeObject<T>khớp tên property không phân biệt hoa thường, không đổi tên: đổi tên field thì key cũ trên server rơi thành default im lặng. Key thừa bị bỏ qua

Giá trị có cấu trúc khai RemoteConfig<MyData> với class dữ liệu thuần, không RemoteConfig<string> rồi tự parse. JSON hỏng thì hệ tự LogError và giữ cache; consumer không try/catch.

Flow

Initialize · FetchAndActivateAsync ─► apply ─► OnRemoteConfigsApplied

Một biến: giá trị nào thắng

ApplyRemoteValue(provider) — dừng ở bậc đầu parse được

Hợp đồng provider

Thành viênHợp đồng
FetchAndActivateAsync(timeout, ct)chỉ lời gọi đầu có tác dụng · chờ tối đa timeout (giờ thật) rồi activate bản mới nhất đang giữ · fetch về muộn để phiên sau · IsFetched = true rồi bắn OnFetched đúng một lần ở mọi đường ra: xong, lỗi, quá hạn, huỷ
TryGetRemoteValue(key, out value)false khi server không khai key; chuỗi rỗng server trả về thì true để RemoteConfig<T> xử lý ca rỗng
IsFetched · event Action OnFetchedcollection dùng cặp này để không phụ thuộc thứ tự khởi tạo
