Cách dùng

Trước khi chạy

Dựng từ 0 theo thứ tự; mỗi bước kèm chỗ hỏng nếu thiếu.

  1. Khai enum key với số tường minh từ = 1; số đã lưu vào asset thì chỉ thêm ở cuối.
  2. Khai lớp con rỗng, đóng key và mang [Service] (Sisus Init): 
    [Service(typeof(IPoolService<MyPool>), FindFromScene = true)]
public sealed class MyPoolService : PoolService<MyPool> { }
    Lớp con không viết OnDestroy: base có OnDestroy private gọi ReleaseAll, lớp con viết OnDestroy riêng là che nó.
  3. Trong scene sống suốt phiên, tạo GameObject, Add Component MyPoolService. GameObject này là cha của mọi instance đang nằm trong pool.
  4. Ô Pool Configs: mỗi phần tử điền Key, Prefab (prefab Addressables), Initial Pool Size, Max Pool Size. Bấm nút Validate Configs, Console không có lỗi.
  5. Mỗi prefab có đúng một component cài IPoolable (thường kế thừa PoolableBehaviour) trên GameObject gốc. Kiểu T khi Get<T> là component đó.
  6. Chỗ đổi màn của dự án: await IPoolService<MyPool>.Service.WarmAsync(ct) trước khi load màn dùng pool, một lần mỗi lần vào; IPoolService<MyPool>.Service.ReleaseAll() khi rời màn.
  7. Trước khi cha của một instance bị huỷ (unload scene, Destroy root level), Return instance đó.

Gọi gì, khi nào

Truy cập qua IPoolService<TKey>.Service (thiếu service thì throw) hoặc IPoolService<TKey>.TryGet(out service).

GọiKhi nàoNhận được
WarmAsync(CancellationToken ct)vào màn dùng pool, trước khi load mànprefab đã load, initialPoolSize instance tắt mỗi key
Get<T>(TKey key, Transform parent)cần một instanceinstance đã active, con của parent, đã gọi OnGetFromPool; caller tự đặt vị trí
Return<T>(T instance)xong việc với instance, trước khi cha của nó bị huỷinstance về pool, hoặc bị Destroy nếu stack đầy
ReleaseAll()rời màn dùng poolmọi instance bị Destroy, prefab được release

Viết prefab và gọi pool

public sealed class Piece : PoolableBehaviour
{
    private Tween _idle;

    public override void OnGetFromPool() => _idle = Tween.Scale(transform, 1.05f, 0.6f, cycles: -1, cycleMode: CycleMode.Yoyo);

    public override void OnReturnToPool() => StopAll();

    private void OnDestroy() => StopAll();

    private void StopAll()
    {
        _idle.Stop();
        transform.localScale = Vector3.one;
    }
}

// phía dùng
Piece piece = IPoolService<MyPool>.Service.Get<Piece>(MyPool.Piece, row);
piece.transform.localPosition = slotPosition;
// ...
IPoolService<MyPool>.Service.Return(piece);

Flow

Vòng đời theo màn

WarmAsync ─► Get / Return qua mọi level ─► ReleaseAll

Ba chỗ của một instance

mỗi instance ở đúng một chỗ: stack inactive · bảng active · đã Destroy
ChuyểnThứ tự callback Unity và hook
WarmInstantiate con của pool → Awake, OnEnable → SetActive(false) → OnDisable
Get, lấy từ stackSetParent(parent) → SetActive(true) → OnEnable → OnGetFromPool
Get, stack rỗngInstantiate ở gốc scene → Awake, OnEnable → SetParent(parent) → OnGetFromPool
ReturnOnReturnToPool → SetActive(false) → OnDisable → SetParent(pool)
Return, stack đầyOnReturnToPool → Destroy (cuối frame OnDisable, OnDestroy)
ReleaseAllDestroy (cuối frame OnDisable, OnDestroy); không OnReturnToPool

Prefab gốc active thì Awake/OnEnable chạy ngay lúc Instantiate.
