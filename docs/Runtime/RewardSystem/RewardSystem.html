Cách dùng

Trước khi chạy

Dựng từ 0 theo thứ tự; mỗi bước kèm chỗ hỏng nếu thiếu.

  1. Service. Trong scene sống suốt phiên, tạo GameObject, Add Component RewardService. Không cần Initializer, không kéo vào ô Steps của BootstrapService.
  2. Loại thưởng. Dự án khai mỗi loại một const int: 
    public static class RewardTypes
{
    public const int Coin = 1;
    public const int Booster = 2;
}
  3. Handler. Mỗi loại một handler, đăng ký trong Start, cùng scene sống suốt phiên với service: 
    public sealed class CoinRewardHandler : MonoBehaviour, IRewardHandler
{
    private void Start() => IRewardService.Service.Register(RewardTypes.Coin, this);

    public void Grant(in RewardData reward, string placement)
    {
        // Ghi reward.Amount vào ví; placement tới analytics của ví.
    }
}
    Một handler phục vụ nhiều loại: gọi Register mỗi typeId một lần, trong Grant rẽ nhánh theo reward.TypeId.
  4. Caller. Grant trước, anim sau: 
    IRewardService.Service.Grant(new RewardData(RewardTypes.Coin, 50), "level_complete");

Vòng đời

thời gian ─► · bảng sống theo object service, không có unregister
Không hàng đợi, không unregister. Grant trước Register của handler thì thưởng mất; handler destroy vẫn nằm trong bảng tới khi service destroy.

Lưu ý

ChỗSự thật
Grant trước Start của handlergrant trong Awake, hay luồng boot chạy trước Start, ra No handler for type …; thưởng mất, không hàng đợi. Grant từ luồng chạy sau Start của mọi handler
Handler ở scene ngắn hơn servicescene unload: bảng giữ handler đã destroy; grant gọi vào nó, chạm API Unity thì MissingReferenceException. Scene load lại: Register ra Type N already has a handler. và giữ bản đã chết. Handler sống cùng scene với service
Handler ném exceptionservice không try/catch: exception lên tới caller, phần sau Grant của caller (anim, popup) không chạy. Handler gặp input sai thì log, không ném
Không phải boot stepkhông kéo RewardService vào ô Steps của BootstrapService: service chỉ cần tồn tại trong scene để FindFromScene thấy
Đăng ký ở Start, không ở AwakeFindFromScene resolve service khi scene đã load; Awake có thể sớm hơn object service
